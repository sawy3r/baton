# Baton v1.0.0-rc.15.1 — ship the board kit

RC15.1 preserves the compact semantic-planning behavior of RC15 and adds the
existing read-only board kit to the generated installation payload.

The payload now contains the five standalone Agent Skills plus the
`baton-board` support package. Its oracle projects committed Baton records and
Git history; the terminal renderer and local Web UI consume that projection.
The board does not mutate repositories, dispatch agents, or own runtime worker
state. Sworn's protocol and runtime ownership are unchanged.

## Payload

The complete payload is bound by the generated manifest in
`skills/.baton-payload.json`. The board entrypoints are:

```text
sha256:a3edf37ad562d559694f69e2d6fdf1e20bdc5e06dc98a008daba0a37c8282826
```

```text
baton-board/reference/board/oracle.mjs
baton-board/reference/board/terminal.mjs
baton-board/reference/board/web.mjs
```

The payload fingerprint is recorded in the manifest and must be used for the
immutable RC15.1 publication.

## Publication

This candidate has a new immutable identity because RC15 remains unchanged.
RC15.1 is additive packaging only; it does not require a Sworn version bump.
