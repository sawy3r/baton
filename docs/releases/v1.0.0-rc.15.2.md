# Baton v1.0.0-rc.15.2 — restore slice boundaries and evidence bundles

RC15.2 restores the useful per-slice boundaries from early Baton without
bringing back mutable `status.json`, `journal.md`, or `proof.md` lifecycle
files.

New plans use a release skeleton in `plan.md` plus one immutable contract file
per slice. This makes concurrent editing safer and lets the validator retain an
unchanged verified slice mechanically.

Slices may also publish human-readable evidence bundles under the configured
release-docs root. The default is `docs/baton/releases`; users can set a
global standard in `~/.config/baton/config.json`, and projects can override it
in `.baton/config.json`. The advisory `evidence.json` inventory can describe
screenshots, recordings, output snippets, and other proof artifacts without
becoming another strict protocol schema.

Existing v2 plans remain readable. The payload includes the plan, slice, and
evidence templates.
