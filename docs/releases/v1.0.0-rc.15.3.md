# Baton v1.0.0-rc.15.3 — make parallel touchpoints explicit

RC15.3 adds an optional `touchpoints` matrix to v3 release skeletons. Each
`scope.include` path can be assigned to its owning track; shared paths are
valid only when the tracks are explicitly ordered. The validator rejects
missing ownership, scope/matrix mismatches, unknown tracks, and unordered
parallel sharing.

This is a concurrency declaration, not a candidate-path allowlist. Existing v2
and v3 plans without a matrix remain readable. New planning templates include
the matrix and require planners to keep it aligned with each slice contract.
