# Baton v1.0.0-rc.3 — exact refs fail closed

RC3 is a narrow maintenance candidate for Baton's Git record boundary. It
keeps the RC2 protocol, roles, operations, schema, board, driver seam, and
installer contract unchanged.

The change closes one representation race: an exact Baton branch must remain a
direct commit ref when it is read, while Git holds its exact transaction lock,
and after the transaction helper returns.

## What changed

### Exact capture

Captured branch heads now include Git's symbolic-ref field. Resolving aliases,
dangling aliases, direct non-commit refs, and broken refs fail closed instead
of being treated as a direct commit or a genuinely missing branch.

Git 2.43 omits dangling aliases from `for-each-ref`. RC3 therefore uses bounded
trusted `symbolic-ref` and `show-ref` probes only for requested refs omitted
from the normal batch.

### Locked refusal

Exact create, update, and verify operations use Git's prepared
`update-ref --no-deref --stdin` transaction. While Git holds the exact named
locks, a small same-module helper rechecks representation, existence, object
type, and expected OID. An alias or moved pre-state aborts before commit.

The helper runs through absolute Node and Git paths, a closed bounded request,
a sanitized environment, disabled fsmonitor, and an empty hooks directory.
The public API remains synchronous.

### Authoritative outcome

A helper can fail after Git has already committed. RC3 therefore decides the
result from a fresh exact-ref snapshot after every helper outcome:

- every ref at the desired direct state is success, including an exact retry;
- every ref at the pre-state after a meaningful transaction is the existing
  snapshot-scoped no-advancement failure; and
- a mixed state, third state, alias, invalid representation, or failed
  reconciliation is an explicit recovery-required ambiguity that must not be
  retried automatically.

An all-pre snapshot cannot prove that no transient commit-and-revert occurred.
RC3 states that ABA limit directly; reflogs are not treated as universal
transaction authority.
