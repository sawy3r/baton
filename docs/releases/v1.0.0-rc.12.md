# Baton v1.0.0-rc.12 — plain language, same trusted handoffs

RC12 makes Baton easier to understand without changing what it protects.

The README, install guide, five skills, examples, errors, and read-only boards
now lead with:

1. what happened;
2. what it means;
3. what happens next; and
4. technical details when they are useful.

The release keeps the same five roles, operations, verdict tokens, plan and
receipt formats, error codes, Git bindings, and stop conditions. It adds no
role, schema, gate, lifecycle, or language-checking process.

The normal four-handoff skill load is 1,497 fixed words, down from 1,509 in
RC11.
