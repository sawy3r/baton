# Baton v1.0.0-rc.13 — let the target move

RC13 stops ordinary target movement from restarting approved work.

Tracks keep the target commit that was approved as their stable working floor.
When every slice has passed, Baton builds the complete release from the latest
target and the exact passed track products, then sends that assembly to a fresh
Verifier.

If the same target branch advances after assembly `PASS`, Baton rebuilds and
rechecks only the assembly. It does not revise the plan, replace slices, or
recertify unchanged work. If target history was replaced and no longer descends
from the approved commit, Baton pauses with `TARGET_DIVERGED` so the history can
be reconciled. It does not assume a plan change.

Assembly records the exact target it used, and final Merge checks that target
again immediately before changing it. A false binding or real product conflict
still stops without moving a branch.

RC13 adds no role, schema, receipt, gate, command, lifecycle stage, or required
document.
